# VisitanteRD
<!-- impeccable:product-schema: 1 -->
## Platform
web
## Purpose
Base del sistema de recepción de visitantes con React/TypeScript, NestJS, SQL Server y licenciamiento centralizado Ed25519.
## Audience and use
Supuesto de esta fase: personal de recepción en un equipo Windows, usando teclado durante la jornada. El detalle del flujo acordado no está disponible en la conversación recuperada.
## Scope
Demostración con datos sintéticos, contratos de visita, verificación de licencias y adaptador de consulta al padrón. Sin despliegue ni datos reales.
## Stack
Monorepo npm, React, TypeScript, NestJS, SQL Server. Futuro instalador Windows.
## Principles
Información clara, permisos mínimos, sin escritura en el padrón, claves privadas exclusivamente en el servicio central. Las capacidades pendientes se identifican como tales.
## Accessibility
Etiquetas visibles, navegación con teclado, estados anunciados y diseño adaptable.
